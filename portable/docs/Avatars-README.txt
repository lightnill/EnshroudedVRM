Put your own .vrm files here, then select one from the avatar list in the F8
in-game menu. Use Browse... in F8 to choose a model stored elsewhere.
No model is selected automatically just because this folder contains one file.
After selection, the model choice is saved for future launches. If a model is
moved or deleted, open F8 and choose its new location or another model.

No sample, diagnostic variant, private model or avatar license is included.
Only use and share models whose owners permit the intended use. The mod's MIT
license does not license any avatar you add to this folder.
