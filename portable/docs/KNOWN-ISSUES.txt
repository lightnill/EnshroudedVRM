EnshroudedVRM 0.4.0 — current bugs and incomplete features

This implementation is still buggy and incomplete. It is not at the intended
quality/stability level. There is no Preview suffix in the release name.

Only Steam game build 26430625 is supported, executable SHA256
5d9ef2f140b8ed49e30dbee655841b89d08baec20f799a1817e171a18a850c77.
Keep 0.3.3 for old build 26320373. Do not mix files from different releases.

SHADERS / IMPORTER
Auto/Enhanced support standard normal maps and selected VRM0/VRM1 MToon
matcap/rim maps and masks. This improves import compatibility; it does not prove
that any unavailable user model is fixed. Full Unity/MToon, custom shaders,
outlines, UV animation and arbitrary gloss/roughness masks are unsupported.
Reflections, matcaps, transparency and low-light brightness can look incorrect.
Matte does not necessarily remove authored reflective effects. Try Fast when
Auto/Enhanced looks wrong. Native characters also show some night underlighting.
16-bit PNGs decode into RGBA8; high-depth shading is not preserved.
Large avatars may exhaust RAM/VRAM, stall or fail. F8 memory figures are estimates,
not total process/driver memory; structural/decoder/device/allocation limits remain.
Optional shader preparation runs in the background. Previews can remain native
temporarily; basic rendering may be used until an enhanced variant is ready.

PLAYERS / ANIMATION
Other players default to native models. Assignments are local and remembered per
account on this PC. Player N labels may change. Nothing sends model files or
preferences to another client. Remote world models work; remote previews are not
included. Shader profiles are shared by model content, not private to a player.
OTHER PLAYERS' VISEMES / AUDIO LIP SYNC ARE NOT IMPLEMENTED.
Voice source and mouth settings always animate You. Game voice needs active
in-game voice chat; local microphone works offline and ignores game mute/PTT.
Native armor is not fitted automatically to the VRM.

FALLBACKS / PERFORMANCE
Brief native-avatar fallbacks and stutters remain, including a short wall-only
visibility gap. A remote weapon may appear before its replacement body. Desktop
two-player diagnostics recorded brief submission declines recovering in about
31-32 ms. Laptop first-minute history includes preparation gaps, a 38 ms mod
submission peak and a 1.72-second CPU Present interval; these do not establish
steady-state cost or the cause of the long interval. No FPS guarantee is made.
Two-player replacement was checked on desktop and laptop. Coverage is limited.

REPORTS / STARTUP
Reports cover bounded recent activity, not an entire session. Missing fields are
marked unavailable; laptop graphics settings were absent in one validation report.
Voice settings show the capture-time source, not complete audio-use history.
Terrain context is observed rendering; actual voxel blocks/saves are not extracted.
Coordinates are inside Enshrouded, never real-world location.
Approved screenshots may include names/chat. Review before sharing. Do not share
raw runtime.log, player-model-assignments.json, the installation key or local paths.
Nothing uploads automatically.
The retained bootstrap targets the default C:\Windows system Vulkan loader.
Other Windows-directory layouts are unsupported. Another vulkan-1.dll conflicts;
an already-loaded system loader may bypass the mod. Do not overwrite other mods'
DLLs or disable antivirus/compatibility checks to force loading.
