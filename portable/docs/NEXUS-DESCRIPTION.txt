[size=5][b]EnshroudedVRM[/b][/size]
By lightnill — 0.1.1 preview

Play Enshrouded as your own VRM avatar. The mod uses your graphics card to help animate the model and reduce CPU load. This is an early preview and still being improved. Right now, only you see your replacement avatar. Multiplayer avatar support is planned, but is not implemented yet.

Use your own VRM avatar as a local cosmetic character replacement in Enshrouded. Includes GPU skinning, lit rendering, spring bones, menu previews and held-item alignment. Finger mappings are preferred; missing optional mappings use an approximate wrist fallback.

[b]Installation[/b]
1. Download the main CMD package and extract the entire ZIP to a writable local folder outside the game directory.
2. Start Steam, then open Launch-EnshroudedVRM.cmd.
3. Choose your own .vrm. Select enshrouded.exe only if automatic detection cannot find a supported installation. Review the paths, then type Y for the first launch.
4. Use the generated Play-EnshroudedVRM.cmd for subsequent launches with your saved avatar and settings, without selecting files or typing. Offline play is the tested path.

Run Launch-EnshroudedVRM.cmd again to change avatars or repair paths; close the game first. Starting through Steam alone runs the normal game. To uninstall, close the game and remove the extracted mod folder.

[b]Requirements[/b]
Windows 10/11 x64 with the built-in Windows PowerShell 5.1. Supported Steam executable: build 26082781, game resource version 1273043. Other executable builds are rejected. Existing script policies are respected; restrictive policies may block the launcher. No administrator rights, Python or additional mod framework is required for players.

The package uses readable CMD/PowerShell launchers and a required native VRM runtime DLL. No custom launcher EXE, avatars or game executables are bundled. Bring a VRM you have permission to use.

[b]Features[/b]
• VRM 0.x/1.x humanoid loading within importer bounds.
• GPU skinning, lit rendering and relaxed hair/clothing spring motion.
• Main-menu, character-selection, Character-panel and world previews.
• Sword/shield, two-handed tool and drawn-bow alignment, with optional wrist fallback for missing finger mappings.
• Portable settings and bounded text logs in the local State folder.

[b]Limits[/b]
Only you see the replacement; multiplayer avatar synchronization is not included. Large models/textures can reduce FPS. Unusual hands and equipment/animation combinations need broader coverage. Menu previews approximate blended materials with a 0.5 alpha cutoff; standard VRoid eyebrow overlays also use cutout in the world; other world blending is unchanged. Native armor/helmet fitting is not included. Read KNOWN-ISSUES.txt in the download.
