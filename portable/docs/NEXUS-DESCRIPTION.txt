[b]EnshroudedVRM0.3.3 — Steam game build26320373[/b]
Play Enshrouded as your VRM avatar. Launch normally through Steam and configure models, lip sync and shader/material presets with F8. No separate launcher, batch file, PowerShell startup command or other mod loader is required.

[b]Which version?[/b]
0.3.3 is for current game build26320373. The retained0.3.2 download is for previous game build26082781 (resource1273043). Do not mix files from those packages.

[b]Manual installation[/b]
Close Enshrouded. Open its installation folder through Steam > Manage > Browse local files. Extract EnshroudedVRM-0.3.3.zip and copy vulkan-1.dll plus the entire EnshroudedVRM folder beside enshrouded.exe. Avoid an extra nested folder. If another mod already supplies vulkan-1.dll, stop rather than overwrite or rename it. Update a known EnshroudedVRM installation as a complete set with the game closed; preserve personal models and preferences.
Launch normally through Steam. Press F8 (Fn+F8 on some laptops), choose Browse... or a listed VRM, and disable No model replacement if enabled. The optional vroid-sample.vrm is not selected automatically. GitHub Source code archives are not the player package.

[b]Features[/b]
Local-player replacement; VRM inventory previews with native survivor previews; held equipment; live model switching; Game lighting/Matte presets and individual material overrides; saved model/appearance preferences; original-character toggle; optional VRoid sample; Game voice lip sync and offline Local microphone with Windows default or selected input. Multiplayer avatar synchronization, native armor fitting and full MToon are not implemented.

[b]Voice[/b]
Opt in through F8. Game voice requires a voice-enabled session and follows available game outgoing audio. Local microphone works offline and independently of game mute/push-to-talk. Audio is processed locally, never recorded/uploaded by the mod, and no extra viseme network messages are sent.

[b]Debug reports and privacy[/b]
F8 > Create debug report saves a local ZIP; Open reports folder opens its location. Nothing uploads automatically. Reports reconstruct approved diagnostics/settings/hardware/model statistics and observed rendering context, with fresh qualified in-game XYZ coordinates when available. No real-world location, actual voxel blocks, saves, raw logs/settings, account/server IDs, endpoint IDs, personal paths, audio, models or memory dumps are attached. Screenshots start off; optional images require exact-image preview and explicit inclusion. Visible names/chat can remain in an approved image. Review the ZIP before sharing. Saved voice settings describe capture time; source history is not exported.

[b]Coverage[/b]
This update passed desktop startup/F8, world/equipment, inventory/survivor/inventory, title/character reload and both voice-source checks. Fresh Ultra-fog hotspots, persistence, optional screenshot and laptop checks remain coverage gaps on this patch. Large avatars can reduce FPS. Windows11, other Windows-folder layouts and combined-loader operation remain unverified. Settings stay under %LOCALAPPDATA%/EnshroudedVRM/State.
