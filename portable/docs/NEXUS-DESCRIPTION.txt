[b]EnshroudedVRM 0.3.1 — play as your VRM avatar[/b]

Install the game-local mod, launch Enshrouded normally through Steam, and press F8 to configure it. This standalone package needs no launcher EXE, batch file, PowerShell startup command or separate mod loader.

[b]Included[/b]
• F8 model switching and a persistent No model replacement option for the original game character.
• Audio lip sync from game voice, or an opt-in local microphone for offline use. Windows default and a device picker are supported.
• Strength/sensitivity/smoothing controls, whole-model Game lighting/Matte presets and saved per-material overrides.
• Lightnill's optional unchanged VRoid sample, never selected automatically. The model keeps its embedded permissions.

[b]0.3.1 changes[/b]
Higher-fog compatibility through a packed, budget-checked lighting-volume snapshot; local-player-owned part selection and corrected ownership recovery; transient GPU/menu/readback lifetime fixes; bounded local fallback and sampled performance diagnostics. Includes the 16-bit PNG importer compatibility from 0.3.0.

[b]Manual installation and updates[/b]
1. Close Enshrouded. In Steam choose Manage > Browse local files.
2. If vulkan-1.dll belongs to another mod, stop; do not overwrite, rename or chain it. Update only a known EnshroudedVRM installation.
3. Copy vulkan-1.dll and the EnshroudedVRM folder from this ZIP beside enshrouded.exe. Keep your personal VRMs and preferences. Replace this package's runtime/shader files together.
4. Start through Steam. Press F8 and select a VRM using Browse or the model list. Enable No model replacement to use the original character; disable it to restore your saved VRM.

The old 0.2.0 script launcher is not used by this package. Preferences live in %LOCALAPPDATA%/EnshroudedVRM/State. To import old package preferences once, copy only avatar-settings.json and mod-settings.json into EnshroudedVRM/State beside Runtime before launch. Existing user-folder files win. Old launcher settings.json is not imported. See the included README for details.

[b]Coverage and known limitations[/b]
This preview targets the checked Steam build 26082781/resource 1273043 and Windows x64 with Windows installed in C:\Windows. Desktop evidence covers Windows 10 build 19045 and Vulkan loader 1.4.350. Other Windows layouts, Windows 11, other loaders and combined-loader operation remain unverified. Game/package checks intentionally decline unsupported files; do not bypass them or disable antivirus.

Some camera/scene/menu fallbacks and survivor-preview subject identification remain under investigation. Stutters can occur at voxel-built bases; a full VRM-off comparison reduced but did not eliminate them. The new timings help investigate the added overhead; no measured gameplay FPS improvement is claimed. Large avatars can reduce performance. Full MToon/native armor fitting and multiplayer avatar synchronization are not implemented. Replacement remains local to your client.

Game voice requires a session with voice chat active. Local microphone works offline and is independent of game mute/PTT. Microphone audio is not recorded or uploaded. F8 No model replacement stops replacement work while leaving the mod loaded. Settings/logs stay local; no automatic updater or global loader installation is used.
