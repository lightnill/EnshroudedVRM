Local VRM catalogue and included sample.

Put your own authorized VRM files here and refresh the list in F8, or use Browse
to select a model elsewhere. Keep a separate copy before updating/removing the
mod folder.

vroid-sample.vrm is an original sample assembled by Lightnill with VRoid Studio
default assets, included unchanged with the creator's permission. Choose it in
F8 to try the mod; it is never selected automatically. Credit Lightnill when
using the sample. Its embedded VRM 1.0 permissions govern the avatar separately
from the mod's MIT source-code license. The export permits redistribution and
requires credit, lists commercialUsage as personalNonProfit and modification
as prohibited. The original permissions and creator information remain in the
VRM file. Do not treat the mod's code license as a license for every avatar.

Enable No model replacement in F8 to return to Enshrouded's original character.
Your selected VRM, recent list and shader settings are remembered. Disable that
switch to resume using the VRM. When replacement is off, model and appearance
controls are greyed out. A loaded avatar is cached for quick return; a disabled
startup does not load the saved avatar until replacement is enabled.
